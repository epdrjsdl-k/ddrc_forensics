CORE FEATURES

세 단계로 끝내는 모바일 포렌식

수집부터 분석, 뷰어·보고서까지 — 하나의 흐름으로 통합되어 있습니다.

Acquisition
데이터 수집

USB로 연결된 단말에서 App Data·User Data·미디어·메타데이터를 sweep해 단일 ZIP으로 패키징합니다.

  • ADB 기반 전체 수집
  • 무결성 보고서(PDF) 자동 생성
  • MD5·SHA1·SHA256 해시
Analysis
데이터 분석

백업·덤프 폴더를 불러와 메시지·미디어·사용자·시스템 등 카테고리별 아티팩트를 자동 추출·분석합니다.

  • Android backup · iTunes 백업
  • iOS NSKeyedArchiver 파싱
  • 카카오톡·인스타그램 DM 복원
Results
뷰어 · 보고서

완료된 케이스를 통합 뷰어로 열어 타임라인·증거 트리를 확인하고 의뢰인용 보고서를 생성합니다.

HOW IT WORKS

단순한 4단계 워크플로우

연결부터 보고서까지, 표준화된 절차로 누구나 빠르게 진행합니다.

  1. 01
    연결·불러오기
    USB로 단말을 연결하거나 백업·덤프 폴더를 불러옵니다.
  2. 02
    수집·추출
    무결성을 유지한 채 데이터를 수집하고 아티팩트를 추출합니다.
  3. 03
    분석·탐색
    통합 뷰어로 메시지·미디어·타임라인을 정밀 분석합니다.
  4. 04
    보고서 생성
    결과를 의뢰인용 보고서로 정리해 한 번에 출력합니다.

WHY MYCRO

왜 MYCRO Mobile 인가

01

증거 무결성 보장

수집 원본의 MD5·SHA 해시를 기록하고 무결성 보고서를 자동 생성해 법적 효력을 확보합니다.

02

깊이 있는 파싱

iOS NSKeyedArchiver(bplist) 역직렬화 등 단순 추출을 넘어 실제 대화·콘텐츠까지 복원합니다.

03

통합 워크플로우

수집·분석·뷰어·보고서가 하나로 이어져, 도구를 옮겨 다닐 필요가 없습니다.

04

독립 실행 뷰어

분석 결과만 따로 열어보는 MYCRO Viewer를 제공해 협업·검토가 편리합니다.
